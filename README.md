# TagUp Frontend

친구끼리 초대코드로 방("더그아웃")을 만들어 **KBO 경기를 보면서 타석마다 내기**를 거는
앱. React Native + Expo.

내기 대상은 돈이 아니라 "커피 한 잔" 같은 텍스트다. 타석이 시작되면 방에 중계가 뜨고,
아웃/세이프에 걸면 타석이 끝나는 대로 서버가 자동 정산한다.

- 백엔드: [tagup-backend](https://github.com/SangHyun-e/tagup-backend) (Spring Boot)
- Expo SDK 54 / React Native 0.81 / expo-router / TypeScript / Zustand
- Firebase Auth(로그인) · Firestore(채팅)

---

## 화면

| | |
|---|---|
| 홈 | 오늘의 경기(진행 중이면 실시간 점수·이닝·주자), 내 더그아웃 목록 |
| 채팅 | 메시지 + 타석 중계 + 내기 카드. 타석이 열리면 카드에서 바로 건다 |
| 내기 | 방의 내기 목록과 상태 (콜 대기 / 성립 / 종료) |
| 경기 일정 | 날짜별 KBO 일정과 결과 |
| 프로필 | 응원 구단, 알림, 차단 목록, 계정 삭제 |

## 설계에서 신경 쓴 것

### 아웃·세이프를 빨강·초록으로 쓰지 않는다

초록은 이미 브랜드 색이라 부딪히고, **적록색약이면 둘을 구분하기 어렵다.** 주황(아웃)과
파랑(세이프)은 밝기도 달라 흑백으로 떨어뜨려도 구분된다. 색과 함께 아이콘을 같이 써서
색 하나에만 기대지 않는다.

### 굵기를 `fontWeight`가 아니라 폰트 이름으로 준다

안드로이드는 커스텀 폰트에 `fontWeight`를 먹이지 않고 가짜 굵기를 그리거나 무시한다.
Pretendard를 굵기별로 따로 싣고 이름으로 고르는 `Text` 래퍼를 뒀다.

### 경기 카드를 한 덩어리로 읽는다

보이스오버는 화면에 보이는 순서대로 하나씩 읽는다. 그대로 두면 "7회초", "두산", "3", ":",
"5"가 따로 들려 **무슨 경기인지 알 수 없다.** 카드를 묶어 "두산 대 LG, 3 대 5, 7회초,
2아웃 주자 1루, 잠실"처럼 문장으로 읽게 했다.

선택 상태를 색으로만 알리던 곳(날짜 탭, 구단 선택)에도 상태를 따로 실었다.

### 알림 권한을 묻기 전에 설명한다

iOS 권한 창은 **한 번 거절하면 앱에서 다시 띄울 수 없다.** 전에는 로그인하자마자 아무
설명 없이 그 창이 떴다. 무슨 알림인지 모르고 거절한 사람은 내기 제안이 와도 모르게 되고,
되돌리려면 iOS 설정까지 들어가야 한다. 무엇을 보내는지 먼저 보여주고 그다음에 묻는다.

### 신고와 차단을 한 화면에 둔다

불쾌한 메시지를 본 사람은 보통 둘 다 하고 싶은데, 신고하고 나서 차단하러 다시 찾아
들어가게 만들면 **그 사이에 또 그 메시지를 보게 된다.**

신고할 때 메시지 내용을 사본으로 함께 보낸다 — 채팅은 Firestore에 있어 서버가 읽을 수
없고, 상대가 지우면 운영자가 볼 근거가 사라진다.

## 실행

**Node 20이 필요하다** (`.nvmrc`). 18로 돌리면 Metro가 `configs.toReversed is not a
function`으로 죽는다.

```bash
npm install
npx expo start -c
```

`.env.local`에 Firebase 설정과 `EXPO_PUBLIC_API_BASE_URL`이 필요하다. 백엔드를 터널로
띄우면 주소가 자동으로 기록된다 (tagup-backend/TUNNEL.md 참고).
